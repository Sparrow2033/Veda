# Veda

**Veda** — Android-приложение для школьников, которое помогает превращать разрозненные учебные записи в связанную систему знаний.

Проект основан на методе **Zettelkasten**: каждая заметка фиксирует отдельную мысль или учебную тему, а связи между заметками формируют наглядный **граф знаний**.

> От хаоса записей — к системе знаний.

---

## О проекте

Современный школьник ежедневно работает с большим количеством учебной информации: конспектами, домашними заданиями, материалами из разных источников и заметками. Часто всё это хранится в разных местах, из-за чего знания остаются разрозненными, а связи между темами теряются.

**Veda** решает эту проблему через единое мобильное пространство для учебы:

- заметки и конспекты;
- внутренние связи между заметками;
- граф знаний;
- домашние задания;
- расписание;
- настройки внешнего вида и поведения приложения.

Главная идея проекта — сделать не просто блокнот, а цифровую систему мышления для школьника.

---

## Цель проекта

Разработать рабочий прототип Android-приложения, которое помогает школьникам и студентам:

- хранить учебные записи в одном месте;
- видеть связи между темами и предметами;
- планировать домашние задания;
- быстрее повторять материал перед контрольными и экзаменами;
- формировать целостное понимание учебного материала.

## Основные функции

### Заметки

Пользователь может создавать, редактировать и просматривать учебные заметки. Заметки являются основой системы знаний.

### Связи между заметками

Внутренние ссылки позволяют связывать одну заметку с другой. Благодаря этому учебный материал не хранится изолированно, а превращается в сеть взаимосвязанных тем.

### Граф знаний

Граф визуализирует связи между заметками. Узлы графа — это заметки, а линии между ними — связи. Этот модуль помогает увидеть структуру знаний и межпредметные связи.

### Домашние задания

Отдельный модуль для хранения и контроля домашних заданий. ДЗ не смешиваются с заметками и существуют как отдельная часть приложения.

### Расписание

Модуль расписания помогает ориентироваться в учебной нагрузке и держать учебный процесс в одном приложении.

### Настройки

В приложении есть настройки темы, размера текста, сортировки, фильтров и поведения интерфейса.

---

## Архитектура

В основе приложения лежит связка:

```text
UI Layer
Activities + XML layouts + ViewBinding

ViewModel Layer
ViewModel-классы для экранов заметок, ДЗ, графа и настроек

Repository Layer
VedaRepository как центральная точка доступа к данным

Data Layer
Room database + сущности заметок, связей и домашних заданий
```

Ключевые принципы архитектуры:

- не ломать ядро заметок;
- не смешивать заметки и домашние задания;
- хранить связи между заметками отдельно;
- строить граф на основе заметок и таблицы связей;
- развивать проект точечно, без большого рискованного рефакторинга.

## Среда сборки (зафиксированные версии)

Проект проверен и должен собираться **без ручных правок конфигурации** как через `./gradlew`, так и через Android Studio при использовании версий ниже:

- **Android Studio:** Narwhal 2025.1.1+
- **JDK (Gradle JDK):** 17
- **Gradle Wrapper:** 9.3.1 (`gradle/wrapper/gradle-wrapper.properties`)
- **Android Gradle Plugin (AGP):** 9.1.0 (`gradle/libs.versions.toml`)

### Команды сборки (CLI)

```bash
./gradlew assembleDebug
./gradlew test
./gradlew lint
```

### Сборка в IDE (без ручных правок)

1. Открыть проект в Android Studio.
2. Убедиться, что `Gradle JDK = 17`.
3. Выполнить `Sync Project with Gradle Files`.
4. Запустить:
   - `assembleDebug` (Build Variants / Gradle panel),
   - `test`,
   - `lint`.

## Релизный чек-лист (smoke)

Перед релизом обязательно прогнать:

- `./gradlew assembleDebug`
- `./gradlew test`
- `./gradlew lint`

## Научная основа

Проект опирается на метод **Zettelkasten** — систему организации знаний через короткие связанные заметки. В образовательном контексте такой подход помогает не просто сохранять информацию, а выстраивать связи между понятиями, темами и предметами.

Использование графа знаний делает обучение более наглядным: пользователь видит, как отдельные учебные темы складываются в единую структуру.
